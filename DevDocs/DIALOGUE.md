## Abilities

(x🕞) = How long the caster has to execute ability, and also how long the time penalty is.
(+x)  = How long the time penalty is.  

- Navigate
    - Allows very slow control of the Action Pawn. Guide arrows boost the Pawn's speed.
- Brute Force Solver
    - Action Pawn randomly explores the maze.
- A* Solver
    - Action Pawn tries to find optimal path through revealed maze corridors.
- Reveal Path
    - Uncovers a section of hidden maze corridors.
- Program Path
    - Allows the placement of [x] number Action Pawn guide arrows.
- Fight bug
    - Can tap to attack bugs for a set amount of time.
- Weaken bug
    - Reduces a bug's current hitpoints by half (no lower than 1).
- Optimize
    - Reduces the time penalty of all abilities.
